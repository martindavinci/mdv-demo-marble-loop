# Marble Loop

Tre biglie di vetro cadono lungo un muro bianco: ogni colpo su un tubo colorato o su un blocchetto di legno è una nota.
Suonano un medley di classici, in un loop senza fine: l'ultimo istante è il primo.

**Guardalo:** apri `index.html` (anche dal telefono, anche dentro un'app di chat). Tocca lo schermo per il suono.

## In programma

1. W. A. Mozart, *Rondò alla turca* (Sonata K. 331)
2. J. Offenbach, *Galop infernal* (il can-can di *Orfeo all'inferno*)
3. G. Rossini, *Guglielmo Tell*, finale dell'ouverture

Tutto è generato nel browser: la scena con three.js, i suoni con Web Audio. Nessun file esterno.
